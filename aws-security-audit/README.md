# AWS Cloud Security Audit

**Status: In progress**

CIS AWS Foundations Benchmark v2.0 assessment of a live AWS
environment using Prowler. Identifying and remediating critical
and high-severity misconfigurations.

**Scope:**
- S3 bucket public access controls
- IAM policy over-permission review
- CloudTrail logging configuration
- Security group ingress rule audit
- Root account usage monitoring
- MFA enforcement review

**Stack:** AWS · Prowler · CIS Benchmark v2.0 · IAM · CloudTrail · S3

*Prowler findings output, formal security assessment report,
remediation evidence, and post-remediation re-audit screenshots

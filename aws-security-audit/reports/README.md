# Prowler scan artifacts

Generated by **Prowler 5.x** with compliance **`cis_2.0_aws`** (73 checks in the captured runs). JSON exports use **OCSF JSON** format (`*.ocsf.json`). Copies named `before-report.json` / `after-report.json` mirror the OCSF files for easier tooling.

| File | Description |
|------|-------------|
| `before-report.html` | HTML report — baseline with lab misconfigurations |
| `before-report.ocsf.json` | Raw OCSF JSON export (same content as `before-report.json`) |
| `before-report.json` | Copy of OCSF JSON |
| `before-metrics.json` | Summarized counts + top FAIL excerpts (`scripts/parse_prowler_ocsf.py`) |
| `after-report.html` | HTML report — after `run-remediate.ps1` / `remediate.sh` |
| `after-report.ocsf.json` | Raw OCSF JSON export |
| `after-report.json` | Copy of OCSF JSON |
| `after-metrics.json` | Summarized counts + top FAIL excerpts |
| `compliance/before-report_cis_2.0_aws.csv` | CIS framework CSV (before) |
| `compliance/after-report_cis_2.0_aws.csv` | CIS framework CSV (after) |

## Privacy

Scrub **account IDs**, ARNs, bucket names, and user names before publishing this repo publicly if needed.

## Windows: avoid Unicode crash during scan

PowerShell (UTF-8 + UTF-8 mode):

```powershell
chcp 65001 | Out-Null
$env:PYTHONUTF8 = "1"
$env:PYTHONIOENCODING = "utf-8"
```

Or use `scripts/run-prowler-cis.ps1`.
